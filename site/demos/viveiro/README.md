# Verde Vivo — demonstração de site para viveiro

Projeto demonstrativo de uma vitrine digital para um viveiro fictício.

- Página responsiva para celular e desktop
- Catálogo ilustrativo com filtros por categoria e busca
- Seções de apresentação e contato
- Formulário visual sem envio ou armazenamento de dados
- Marca, produtos, preços e conteúdo fictícios

## Visualizar localmente

Abra `index.html` no navegador.

## Personalização para um cliente real

Substituir marca, fotos, produtos, preços, endereço, canais de contato e políticas comerciais somente após receber as informações e autorização do estabelecimento.

As fotografias são carregadas de URLs externas do Unsplash.
