# Portfólio — Emmanuel Rodrigues

Código-fonte do portfólio pessoal.

## Desenvolvimento local

Abra `index.html` no navegador. O site é estático e não exige dependências ou etapa de build.

## Deploy

O projeto pode ser conectado à Vercel usando este diretório como Root Directory (`site`). Depois da conexão, cada push na branch de produção gera um novo deploy.
